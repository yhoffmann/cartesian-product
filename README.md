# CartesianProduct

## How to install

Just include `include/CartesianProduct.hpp`, and everything should work.

## Code explanation and documentation

Most of the important parts of the code are annotated with Doxygen comments.
Just run

```
doxygen
```

in the root of the project, and then open `html/index.html` with your browser.
(You will obviously have to have Doxygen installed for this to work)
